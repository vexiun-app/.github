## What is Vexiun?

Vexiun is a multi-tenant project management platform built for developers, freelancers and technical teams.

Unlike traditional tools focused on visual flexibility, Vexiun focuses on:

- ⚡ Fast workspace setup
- 🧩 Structured task modeling (CoreStatus-driven)
- 🔄 Real-time collaboration
- 🏗️ Scalable architecture from day one

🏗️ Architecture Highlights

- Monorepo structure
- Event-driven backend
- Type-safe fullstack (TypeScript-first)
- WebSocket-based real-time updates
- Performance-aware design decisions
